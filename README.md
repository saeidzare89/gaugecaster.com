# gaugecaster.com

The website of GaugeCaster, served by GitHub Pages at www.gaugecaster.com.

The pages are written in `src/` (the home page by `_tools/index.py`, which draws its pictures of the app; they are illustrations, not screenshots); the HTML at the top level, `img/` and
`terms.html` are generated by `tool/make_site.py` in the app's repository
(the terms from its `docs/terms-of-use.txt`, the images from its brand
sources). Edit `src/`, then run, from the app's repository:

    python tool/make_site.py ../gaugecaster.com

Fredoka (in `fonts/`) is under the SIL Open Font License 1.1 (`fonts/Fredoka-OFL.txt`).
